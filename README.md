# Painel de Acompanhamento de Atividades · ADINS/SEED-AP

Painel interno da Assessoria de Desenvolvimento Institucional (ADINS). O acesso é feito com o usuário e a senha do próprio painel.

- `index.html`: o painel (visual, funções e lista de usuários com as senhas embaralhadas).
- `dados.enc.json`: os dados do painel, criptografados. Sem uma senha válida, o arquivo não pode ser lido.
