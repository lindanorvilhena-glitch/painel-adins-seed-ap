                              Como funciona a segurança

                              • Cada senha abre uma cópia da chave que destrava os dados do painel. A senha em si não fica guardada em lugar nenhum, só uma versão embaralhada que não dá para reverter.
                              • No Claude, só o dono ou um editor consegue salvar alterações. Na versão do GitHub, salvar baixa um novo index.html, que só tem efeito quando você sobe o arquivo no repositório.
                              • Remover um usuário tira o nome da lista e a senha dele deixa de funcionar. Quem estiver logado naquele momento continua até fechar o navegador.
                              • Use senhas com pelo menos 8 caracteres, misturando letras e números. Evite sequências como 123456.

                                      Objeto Categoria Escolas Total

                                      Fonte: planilhas de mala direta e bancos de dados do PROEM da ADINS/SEED (2021: aba MALA ATUAL; 2022 e 2023: MALA último censo; 2024: BANCO DE DADOS; 2025: BANCO DE DADOS DEZ (2); 2026: BANCO DE DADOS abril-dez). Valores do cronograma de desembolso por escola; em 2026 incluem os meses previstos até dezembro. Coordenadas das escolas: Catálogo de Escolas do INEP (via geobr/Ipea, 2025), casadas pelo nome dentro de cada município; pontos sem coordenada do INEP usam geocodificação pelo CEP e aparecem como aproximados. Matrículas, tempo integral, perfil (coluna "localidade") e estruturas financiadas (piscina, quadra, laboratório de informática, internet) vêm das mesmas planilhas; linhas de totais foram descartadas. Como matrícula é um estoque, os indicadores da rede usam o ano escolhido no filtro ou, sem filtro, o último ano.
